# `@cluster-mkt/web`

Responsive React/Vite browser shell for Today, Story Cluster detail, navigation, settings previews, edition accents, and honest demonstration fixtures. It consumes `@cluster-mkt/core`, `@cluster-mkt/config`, `@cluster-mkt/ui`, and canonical assets under `brand/`.

The shell is implemented but has no live feeds, persistence, authentication, AI, audio generation, or publisher connections. `public/brand/` is generated by `pnpm assets:sync` and must not be edited or committed.

`/sectors` and `/sectors/semiconductors` demonstrate scope-aware sector coverage and a shared edition brief using deterministic fixtures. Frontend acceptance requires controlled-browser checks at desktop and mobile sizes, including console and network inspection.
