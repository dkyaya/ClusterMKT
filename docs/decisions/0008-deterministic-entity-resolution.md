# 0008: Separate entity candidates from accepted mentions

Status: accepted

Entity aliases produce candidates; deterministic contextual rules decide acceptance. Ambiguous tickers, products, URL slugs, and untrusted source tags cannot become accepted entities without corroboration. Review-required outcomes remain visible.

No fuzzy matching, embeddings, model confidence, or speculative entity universe is used in this foundation. Future approaches must outperform the reviewed fixture corpus without weakening the zero-false-positive ticker gate.
