# 0009: Define event identity with structured signatures

Status: accepted

Event identity is not publisher plus headline and is not entity plus date. Cluster MKT uses versioned signatures containing event type, actions, entities, identifiers, dates, geography, products, quantitative anchors, and source-family evidence.

High-overlap signatures can represent one evolving event; proposals and final rules, rumors and confirmations, different quarters, and distinct actions remain separate or review-required. This preserves genuine event boundaries before later Story Cluster construction.
