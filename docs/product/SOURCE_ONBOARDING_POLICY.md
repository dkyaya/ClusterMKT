# Source onboarding policy

Public accessibility is not permission. Before any bounded live pilot, Cluster MKT requires reviewed official documentation and terms, recorded technical capabilities and limits, known cost and credential needs, an offline adapter dry run, externally stored secrets, explicit smoke-test authorization, reconciled results, and a separate enable action.

No scraper, premium full-text source, or publisher login may be introduced through this workflow. Sources without approved terms remain disabled. The initial candidate pilot, if calibration passes, should favor SEC public data and one or two formally approved public feeds with small item limits and manual review before display.

No-key sources still require official-documentation, terms, capability, attribution, rate, dry-run, smoke-test, and reconciliation review. Developer keys or OAuth are requested only after those reviews establish a permitted and necessary use. Commercial datasets, licensed full text, real-time market data, and transcript services require an approved commercial agreement before implementation or credential acquisition.

Enabling is a separate explicit state change after all eleven onboarding checks pass. Registration, adapter existence, credential presence, or a successful smoke test never enables a source automatically.
