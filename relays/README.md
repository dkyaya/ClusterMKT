# Relays

## Responsibility

Auditable handoffs for substantial agent phases.

## Belongs here

ZIP files named `cluster-mkt-<phase>-relay-YYYY-MM-DD-<short-hash>.zip` containing changed files, validation evidence, decisions, uncertainties, reproduction commands, plain-English context, and SHA-256 hashes.

## Does not belong here

Extracted relay trees, caches, dependencies, font binaries, secrets, temporary archives, or a prior relay nested inside a new relay.

## Status and dependencies

The completed full-brand-package relay is retained here as historical evidence. New relays are independent, validated archives and must not contain previous relay ZIPs.
